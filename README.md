# game-demo

# Plan
## Big Idea
In undergrad, I used Unity to create an ecosystem simulator based off of conditions and animal populations in Yellowstone. I want to create an adaption of that project using PyGame, where the player's end goal is to maintain an equilibrium between the various species present (maintain populations above zero). The species can evolve over time and follow group patterns, have inheritance, etc. Each individual animal will require water and food. The player is able to shape the environment to include more water or to spawn in more of a specific species, like a sandbox.

## Classes and Structure
    -Animal class 
    -Methods for terrain generation and map formation
    -Core loop for managing simulation ticks and updates along with UI updates

## How to Play
Main file is game_original_logic.py 
Players can click on the two buttons in the left-hand corner to add more bunnies or coyotes in order to maintain both populations above zero. Players can also alter the terrain in order to add more resources like grass or water to help balance the population using **right-click or left-click**. To spawn a new map, players can press **R**.
